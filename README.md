# Smart Expense Tracker

A frontend web app to track daily expenses.

Users can add expenses, view them in a list, filter by category or month, and see spending summaries and charts. All data is saved in the browser, so it stays even after refresh.

---

## Features

- Add, edit, and delete expenses
- Categorize expenses (Food, Travel, Shopping, Bills, Others)
- Filter expenses by category and month
- Sort expenses by date or amount
- Summary cards showing total spending
- Category-wise and month-wise charts
- Data stored using browser LocalStorage
- Responsive layout
